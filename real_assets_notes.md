# Реальные визуальные материалы Горошинки

Проверены два подготовленных файла из переданного скриншота TikTok.

`gorshinka-avatar-real.jpg` содержит настоящую аватарку профиля: круглая розово-белая рамка, персонаж с маленькой куклой и розовый бейдж «Эфир». Размер — 230×230 px; подходит для круглой аватарки в шапке.

Остальные пять файлов выделены из той же сетки и используются как реальные кадры, без стоковых изображений и без сгенерированных замен.
